## Repos

- [claude-skills](https://github.com/iconiksocials/claude-skills): reusable Claude skills that turn repeat work into a one-step process

## Skills

| Skill | What it does |
|---|---|
| [kdp-planner-journal-files](kdp-planner-journal-files/) | Builds print-ready Amazon KDP interiors and cover wraps for planners and journals. Handles trim size, spine width, bleed and KDP's low-content rules. |

## How to use

1. Download the skill folder
2. Add it to Claude as a custom skill
3. Ask for the task in plain words, e.g. *"Make a 120-page undated weekly planner interior and matching cover for KDP"*

More skills added as I build them.
